# Linkina Markdown Editor

一个使用原生 JavaScript 构建的浏览器端 Markdown 文件编辑器，也是个人前端练习项目。布局参考 Obsidian，由左侧文件区、中央文档区和右侧扩展区组成，支持 Markdown 原文编辑与阅读预览。

## 当前功能

- **文件操作**：新建、选择、删除文件，导入 `.md`、`.markdown` 和 `.txt`，导出 `.md`。
- **编辑与阅读**：切换原文编辑和阅读模式，支持标题、列表、任务清单、引用、表格、图片和代码块等 Markdown 内容。
- **代码高亮**：支持 HTML/XML、CSS、JavaScript、TypeScript、JSON、Bash 和 Markdown，未注册的语言按纯文本显示。
- **自动保存**：内容输入后自动保存到浏览器，显示保存状态；保存失败时支持重试或导出当前文件。
- **主题与布局**：亮暗主题切换、左右侧栏收起与展开、拖动调整宽度，并保留用户偏好。
- **首次使用引导**：为新用户创建一份可编辑的欢迎文档，自动以阅读模式打开。

右侧扩展区目前仅保留布局容器，尚未接入具体功能。

## 本地运行

需要安装 Node.js 和 npm。当前 Vite 依赖要求 Node.js `^20.19.0 || >=22.12.0`。

```bash
git clone https://github.com/StarLinkina/Linkina-Markdown-editor.git
cd Linkina-Markdown-editor
npm install
npm run dev
```

打开终端显示的本地地址。已经下载项目时，在包含 `package.json` 的目录中执行安装和启动命令即可。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 生成生产构建，输出到 `dist/` |
| `npm run preview` | 本地预览生产构建，需要先执行 build |

## 使用方式

1. 首次访问且没有已有文件时，阅读自动打开的「欢迎使用 Linkina」。可以切换到编辑模式练习，也可以导出或删除它。
2. 点击左侧工具栏的 **新建文件**，输入标题；或通过 **导入文件** 选择电脑上的 Markdown、文本文件。
3. 点击文件标题选择文档，在 **编辑** 模式输入内容，在 **阅读** 模式查看排版。
4. 将鼠标移到文件项上，或用键盘聚焦文件项，使用 **导出文件** 和 **删除文件** 按钮。
5. 使用右上角按钮切换主题，使用侧栏按钮或两侧分割条调整工作区。

首次引导记录保留后，刷新不会重复创建欢迎文件，删除后也不会重建。已有文件的用户不会被自动插入引导；普通启动和刷新后默认不选中文件，从左侧选择文档即可继续编辑。

## 文件保存说明

文件保存在**当前网站、当前浏览器的 localStorage** 中，不需要账号或后端服务，也不会自动同步到其他设备或浏览器。更换网站地址或本地开发端口后，可能会使用另一份浏览器存储。

- 编辑时立即更新内存内容，停止输入约 400ms 后写入本地存储；新建、删除和导入立即保存。
- 导入的是原文件的副本，在编辑器中修改不会直接改写电脑上的原文件。
- 保存失败时，未保存内容仍保留在当前页面。可重试，或在关闭页面前导出备份。
- 如果已有文件数据无法读取，应用会显示错误并阻止本页覆盖原始存储。

**请及时导出重要文件。** 清除网站数据可能导致文件丢失，浏览器本地存储也有容量限制。删除文件目前没有撤销或回收站。

## 技术栈与代码结构

项目采用 JavaScript ES Modules、原生 DOM API 和 `createXxx()` 组件工厂，使用 Vite 8 开发与构建。

Markdown 由 `marked` 解析，通过 `marked-highlight` 接入 `highlight.js`，最终 HTML 经 `DOMPurify` 清理后显示。主题由全局 CSS 语义变量控制，侧栏使用 Grid、Pointer Events 和 ResizeObserver 实现交互布局。

```text
public/
└─ favicon.svg             LME 网站图标
src/
├─ assets/                 界面图标
├─ components/             按钮、导航栏、文件区、文档区及侧栏布局
├─ content/welcome.md       网站首次使用欢迎文档
├─ models/                 Markdown 文件数据模型
├─ services/               文件操作、保存调度和首次使用初始化
├─ utils/                  存储读写、Markdown 渲染和主题工具
├─ state.js                文件列表与当前选中文件状态
├─ main.js                 应用入口
└─ style.css               全局样式与亮暗主题变量
```

Workspace 负责组件组合与协调；文件业务、保存调度和存储读写分别由独立模块处理。详细职责与开发约定见 [项目交接文档](PROJECT_HANDOFF.md)。

## 当前限制与后续计划

当前以桌面浏览器使用为主。窄窗口会临时收起侧栏，完整的移动端抽屉布局尚未实现；编辑区与阅读区也尚未按源码位置同步滚动。

文件重命名、搜索、PDF 导出、AI 辅助和 Electron 桌面版属于后续计划，尚未实现。具体优先级和暂缓事项见 [TODO](TODO.md)。

当前没有配置自动化测试、lint 或格式化脚本。修改代码后，通过生产构建和受影响的交互回归进行验证。
