# 欢迎使用 Linkina-Markdown-Editor

Linkina-Markdown-Editor 是一个简洁的 Markdown 文件编辑器。你可以在这里写下想法、整理文章，并随时切换到阅读模式查看排版。

这份欢迎文档也是一个普通文件。点击上方的 **编辑**，就能修改它、练习 Markdown；不再需要时，也可以从左侧文件列表删除它。

## 开始你的第一份文档

1. 点击左侧工具栏的 **新建文件** 图标，输入标题，创建自己的文件。
2. 在上方选择 **编辑**，输入 Markdown 原文。
3. 点击 **阅读**，查看排版和代码高亮。
4. 点击左侧的文件标题，可以切换到其他文件。

也可以点击 **导入文件** 图标，选择电脑上的 `.md`、`.markdown` 或 `.txt` 文件。导入后，编辑的是浏览器中保存的副本，**原始文件不会被修改**。

## 保存与导出

输入内容后，Linkina-Markdown-Editor 会自动保存。工具栏中的 **保存中…** 和 **已保存** 会告诉你当前状态。

> 文件保存在当前浏览器中，不会自动同步到其他浏览器或设备。清除网站数据可能导致文件丢失，请及时导出重要内容作为备份。

将鼠标移到左侧文件项上，或用键盘聚焦文件项，可以找到 **导出文件** 和 **删除文件** 按钮。导出会下载一份 `.md` 文件；删除目前没有撤销功能。

如果保存失败，页面会显示原因。你可以尝试 **重试**，或先 **导出当前文件**，保留尚未保存的内容。

## 调整你的工作区

- 点击右上角的主题按钮，切换亮色和暗色外观。
- 点击左右侧区的收起按钮，给正文腾出空间；收起后可以通过边栏按钮展开。
- 拖动文档区两侧的分割条，可以调整侧区宽度。
- 目前工作区右侧的扩展区还未添加功能，仅起占位作用，**建议收起**。

主题和手动设置的侧栏布局会在当前浏览器中保留。以后打开网站时，从左侧选择要继续编辑的文件即可。
